## Outcome and scope

Replace the partial style blacklist with one bounded contract for the original static renderer. Canonical onset requires the retained generated node identities, effective CSS path commands, exact opaque stroke/fill/width/caps/joins/dashes/markers, original viewport and local geometry, and untransformed full ancestry through `html`. Unsupported composition effects, generated content, animation/transition, hidden/clipped paint, changed cue text/paint, and noncanonical row position/order/spacing are rejected. The cue, five symbol viewports and pointer controls must survive relevant ancestor clipping. White backing and transparent stimulus layers are verified. Normal CSS zoom is admitted by matching screen matrices to measured viewport geometry, without assuming scale 1 or multiplying by device pixel ratio.

The same V1.1 presentation check runs on each protected frame while the stimulus is active, immediately before selected input, and before resolution. A rejected first onset records zero presentations; a later alteration retains the truthful onset, invalidates, and fabricates no close or omission. All checks and the onset action remain synchronous; no corrective normalization or awaited work is inserted. Existing timing samples and late-frame ordering remain intact. V1 dispatch remains outside the new predicate; its original renderer, scoring and history behavior are unchanged.

The only product file changed is `src/arrows/browser.ts`. The five new deterministic browser tests exercise before-frame keyboard/pointer and resolution races plus active-frame invalidation and input sampling across the response deadline. Frozen packets, forms/constructors, timings, storage, scoring and all other games remain unchanged.

## Boundaries

This predicate establishes agreement among browser-observed DOM identity, computed paint, local SVG geometry, static ancestry and measured layout at the check boundaries. It cannot certify physical pixels/scanout, hostile scripts replacing measurement APIs, extensions, OS overlays or arbitrary mutations after a callback and before paint. Browser callbacks and screenshots are bounded developer evidence. CSS zoom is tested; native desktop browser zoom, other browser/device combinations, physical timing and assistive output require qualification. Font-family serialization and exposed CSS `d`/SVG geometry/animation APIs are admission capabilities, not silently assumed support.

Ancestor clipping is conservatively bounded: rounded clips use an inscribed rectangle; unsupported transformed/effected surfaces refuse admission. A custom theme or decoration on the protected ancestry can therefore be refused even if a human might still see the row. This static surface is intentional and does not assert support for arbitrary author CSS.

Inherited A11 N1 remains open under its prior nonblocking scope. Founder personal acceptance, independent functional verdict, browser/device/accessibility qualification, full mock, analytics activation, deployment and release remain separate and open.
