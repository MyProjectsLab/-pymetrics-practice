# Arrows A8 — live between-block checkpoint gate

**Base:** clean `5f55b45676bf1109cf1b5763c39e0d961532c16b`. The [independent A7 F1 audit](/private/tmp/arrows-a7-f1-independent-5f55b45/AUDIT.md) passed the storage API repair. This stage connects that API to the live browser adapter at untimed breaks only.

After the last confirmed offset of a block, the adapter ends protection before publishing the break and begins an asynchronous full-journal checkpoint. Timed input and frame resolution do not await storage. `continue()` waits for a confirmed checkpoint and rechecks original arm authority before starting the next protected block. A failed save keeps the attempt at the break and can be retried. A committed save with lost delivery can be recovered from an authoritative snapshot; if the break journal gained later input-release evidence, the newer prefix gets another revision. Canceling the entry aborts a pending checkpoint and releases browser ownership. The adapter exposes `checkpointStatus()` for later UI work.

Lint passed with two inherited warnings; frozen form check and build passed.
