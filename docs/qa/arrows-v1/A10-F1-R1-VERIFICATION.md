# Arrows A10 F1-R1 — definitive terminal retirement

**Base:** `e0bb7a762e9449065a38f1099052c0103d74be7d`. The [independent audit](/private/tmp/arrows-a10-f1f2-independent-e0bb7a7/AUDIT.md) reproduced twelve cases where an earlier-started retry observed deletion or installation replacement after a later-started retry had captured older positive bytes. Invocation generation alone ignored that fresh retirement evidence and later claimed `saved`.

The browser adapter now treats definitive terminal authority failures as irreversible for that run: original arm removal, installation replacement, or a changed terminal result retires outstanding recovery reads and writes regardless of invocation order. It clears the cached saved claim, keeps the immutable in-memory journal reviewable, and rejects later retries for that retired run. Temporary read outages remain retryable; an obsolete temporary failure cannot erase a newer successful confirmation.

They include both pending and saved cases where an older-started check reports retirement before a later positive read delivers, plus the original deletion/replacement ordering, transient outage, late write and same-byte recovery controls. Lint, frozen-form check, TypeScript/production build and `git diff --check` passed; lint retained two inherited warnings. The auditor's four normal-clock digest-order cases were copied outside the repository, pointed at a fresh production adapter bundle of this repair and rerun with real Chromium IndexedDB and Web Locks. All four passed for pending/saved and deletion/replacement; the older positive retry rejected, status stayed `unconfirmed`, and the deleted/replacement root remained unchanged. Adapted driver and raw output: `/private/tmp/arrows-a10-r1/digest-order-normal.mjs` and `/private/tmp/arrows-a10-r1/digest-order-normal.json`. The digest/read delays were injected; no physical input was measured.
