# Arrows A10 P1 — terminal-write authority classification

**Base:** `9d24c2cb2100b90a6df052934726be226966f7dc`. The [independent audit](/private/tmp/arrows-a10-f1r1-independent-9d24c2c/AUDIT.md) found that a late terminal-write readback after deletion can reject with `Arrows storage: snapshot authority changed`. The browser adapter recognized deletion/replacement during direct reads but omitted this write-side error, allowing a cached `saved` claim and older positive read to survive.

The terminal retirement classifier now includes the storage transaction's original-arm authority and arm-prefix failures. They retire outstanding recovery reads/writes regardless of invocation order. Installation replacement and direct terminal authority failures retain the same treatment. A snapshot revision conflict or temporary delivery outage remains retryable, preserving a valid same-byte recovery path.

**Developer verification:** 80 Arrows tests across six files passed. Focused browser tests cover late write authority loss after saved readback, a held older positive read, and obsolete transient/revision errors. Lint, frozen-form check, TypeScript/production build and `git diff --check` passed; lint retained two inherited warnings. Bounded Chromium `145.0.7632.6` ran the independent auditor's four normal-clock terminal-write cases against a fresh source-adapter production bundle with real IndexedDB and Web Locks. All four passed: deletion/replacement with a newer confirmed result and with a held older positive read. The old write's authoritative failure withdrew saved status, the held read could not restore it, and durable roots remained unchanged. Adapted driver and raw results are outside the repository at `/private/tmp/arrows-a10-r1/write-authority-normal.mjs` and `/private/tmp/arrows-a10-r1/write-authority-normal.json`. Delivery stalls were injected; this is not device timing certification.

**Limits:** Developer verification only; a separate exact-SHA independent audit is required. Candidate recovery UI, explicit break exit, reports/history/reload, full mock, browser/device/accessibility qualification, founder personal acceptance, deployment and release remain open.
