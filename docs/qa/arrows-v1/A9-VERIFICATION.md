# Arrows A9 — terminal snapshot foundation

**Base:** clean `c1504d67b3fb990ebab70561e51f7f7fde7487ed`. The [A8 F2 independent audit](/private/tmp/arrows-a8-f2-audit-c1504d6/AUDIT.md) passed the focused F2 repair and bounded A8 checkpoint behavior. A9 connects invalid/completed live journals to the already-validated terminal snapshot storage API.

When the engine reaches Invalid or Completed, the browser adapter first retains its immutable terminal state, ends protection and releases the live Web Lock, then starts an out-of-timing save. A save can finish after navigation/disposal. The adapter reports `pending`, `saved`, or `unconfirmed`; a retry uses the same terminal bytes. The entry method reads the original arm and current revision, accepts an already identical terminal snapshot, and retries one revision race with an in-flight earlier checkpoint. Storage still enforces original installation, arm, tombstone, journal prefix and transaction revision. A deleted attempt cannot be restored by a late terminal write.
