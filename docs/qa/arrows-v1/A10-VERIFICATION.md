# Arrows A10 — terminal readback after indefinitely pending delivery

**Base:** clean `4e14a67284ddef8e00cacd14e10ee048bbb0eac4`. The [independent A9 F1 audit](/private/tmp/arrows-a9-f1-independent-4e14a67/AUDIT.md) passed bounded A9 but retained N1: a terminal transaction could commit while its delivery promise never settled, leaving the adapter's save state pending and its retry attached to that same promise.

`retryTerminal()` now performs an independent authoritative read while a prior delivery is pending. If the exact original terminal journal exists, it marks the result saved without a new write. If absent, it detaches the old callback and writes the same immutable bytes again. A generation fence prevents a late old callback from changing the newer save state. Already-confirmed saves are rechecked on retry, so deletion or installation replacement cannot be presented as a current saved record through that action. The entry readback verifies the original arm, terminal identity and saved journal through the versioned store.

**Developer checks:** 71 Arrows tests passed across six files, including pending committed and uncommitted delivery, late old callback, concurrent readbacks, original terminal bytes, and authority after deletion. Lint, fixed-form check and TypeScript/production build passed; lint retained two inherited warnings. Bounded Chromium with real IndexedDB and Web Locks passed two cases: terminal write committed but never delivered, and terminal write held before commit. Both began in `pending`, recovered to `saved` through retry without another root revision, retained the exact result, and raised no global errors. Probe: `/private/tmp/arrows-a10-browser.mjs`; raw output: `/private/tmp/arrows-a10-browser-results.json`. Write delivery was deliberately held and input was scripted.

**Limits:** A readback itself can be unavailable or indefinitely pending; `saved` is never claimed without confirmation. Candidate navigation must provide a usable retry/recheck control and withdraw saved claims after deletion. This is still a source-adapter foundation.
