Worked post-error example, one-based trial positions: trial 2 is a GO miss and trial 4 is a NO-GO false alarm. The first error opens positions 3–5; the second opens 5–7. Thus the post-accuracy cohort is **3, 4, 5, 6, 7**, counted once each; trial 4 is both an error and a member of trial 2's post window. Trials 1, 2, and 8 onward are in the comparison cohort unless another error's window includes them. For timing after trial 2, an intervening error at trial 4 stops the search; after trial 4, the first timing-clean correct GO hit among trials 5–7 is selected. Accuracy therefore includes mistakes that a correct-hit-only timing cohort would hide.
