## Implementation

- The report offers the assigned exercise only for a saved, valid standalone BL. Assignment runs in one IndexedDB readwrite transaction: it freshly admits the original baseline, derives the deterministic route, binds the chain to BL session/installation/form, core snapshot, mapping, settings and recorded versions, verifies the fixed inventory, and saves one attempt. A resumed attempt keeps the same inventory and journal. A completed chain returns its first completed attempt.
- `balloons-training-storage-v1` records chains and immutable drill journals/snapshots in the existing Balloons installation root. Every training read and write checks original installation and rederives the recommendation from current durable BL authority. Imported drill attempts replay against the verified inventory. The final action, eighteenth result, and first-completion chain lock are written in the same transaction. Its callback is followed by a fresh authority read before candidate-facing eligibility appears. An invalid saved attempt can start a fresh attempt ID at round one on the same inventory, with no eligibility from the invalid attempt.
- The training screen renders only the admitted card, two approved outcome demos, visible Type labels, current/banked amounts, resolved outcomes and drill feedback projections. It does not render raw recommendation/evidence objects, manifest rows, hidden thresholds or journal records. Native Pump/Collect button clicks use the existing source classifier. Further actions are disabled during saves; a failed or uncertain save is reconciled from durable state before controls or eligibility return. Reload, tab changes and baseline deletion force fresh authority checks. Retest eligibility is a durable status only; no retest form is assigned or reserved.
- The training layer does not change B1 scored actions, timing or report arithmetic. The existing installation root has an optional versioned training field so older local B1 roots can be read without migration of scored journals. Original code and copy were authored for Assessment Practice; no competitor asset or expression was copied.
