## Changed boundary

Money Exchange 1 opens in its own same-origin top-level page before a run is armed. At Start, the mutable guide tree is discarded. The active journey is constructed from a finite set of owned native elements under a closed root; the expected topology is generated from the declared stage rather than learned from live DOM. A mutation, unknown painting branch, changed stylesheet, result resource, or mismatched control value withdraws the attempt. The final amounts and labels are an original opaque path-only SVG image, with a matching semantic statement for assistive technology. The existing local authority, frozen forms, stages, outcome arithmetic, Restart/Close, report and history remain in use. Invalid or unconfirmed result presentation ends Incomplete with at least `possibly_revealed`; it does not write `return_presented`.

The exact fixed result image and amount-to-glyph oracle are in `src/money-exchange-1/result-art.ts` and `result-art.test.ts`. The browser display confirmation is bounded at 2.5 seconds so held image decode or animation frames cannot leave the candidate waiting indefinitely.

## Limit

This boundary checks browser-owned DOM/resource composition at the result capture point. It cannot prove physical scanout, human perception, arbitrary browser bugs or real assistive speech. Those require separate qualification. No claim of provider-equivalent scoring or return policy is made.
